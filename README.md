# Michel Domenella — Portfolio Website

Production-ready static website files ready for GitHub / GitHub Pages deployment.

## Deploying to GitHub / Replacing Existing Files:
1. Copy or upload all contents from this folder directly into your GitHub repository root.
2. The `CNAME` file is already included with `micheldomenella.com` to preserve your custom domain.
3. `.nojekyll` is included to ensure GitHub Pages processes all assets properly.
